Person 2, slide 4. This timeline separates the three jobs. The first five years provide initial training. The following year selects the SARIMA specification using forecast errors. We then freeze the selected order for the 2025 test, but refit its parameters when another three months of observations become available. All models forecast exactly the same four blocks at the same horizons. At the start of a block, its next three actual values are unavailable. After a block ends, those observed values can enter the next fit. This prevents information from the future entering a block's forecasts.

Person 2, slide 5. The original seasonal naive rule simply repeats last year's matching months. The new rule also repeats those months but adds a recent average annual change measured in terawatt-hours. We calculate twelve year-on-year differences from observed data and average them. At a given cutoff that same adjustment is used for all three forecast months. This is an additive adjustment, not a percentage growth rate. The SARIMA specification and refitting procedure remain unchanged. We did not search different windows or growth definitions to improve the test score.
