# Forecasting Kazakhstan's Monthly Electricity Generation

Time Series final project for a group of four Mathematics students at Nazarbayev University.

**Question:** Can SARIMA improve three-month forecasts of Kazakhstan's total monthly electricity generation over a seasonal naive baseline?

The selected model is **SARIMA(1,0,0)(0,1,1)[12] with a constant**. On the held-out 2025 test year, its MAE is **0.343 TWh**, compared with **0.435 TWh** for the seasonal baseline, a **21.1% reduction**. Its nominal 95% prediction intervals cover only 10 of 12 observations. These results describe a small historical experiment, with documented source limitations.

## Reproduce the results

Use **Python 3.12**, then run these commands from the repository root:

```sh
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/reproduce.py
```

On Windows, activate with `.venv\Scripts\activate` instead. The numerical libraries are pinned to the versions used in the executed notebook. The frozen inputs are included, so reproduction does not require downloading new data.

The reproduction command:

1. Verifies the frozen original CSV and extracts the national target series.
2. Reads the audited totals directly from the original Samruk DOCX tables.
3. Executes the analysis cells and saves the notebook, figures and CSV results.
4. Rebuilds the ReportLab report and speaking guide.
5. Generates LaTeX from the same report content.
6. Checks hashes, chronological forecast origins, common horizons and reported error calculations.

To rerun only the numerical analysis:

```sh
python analysis.py
```

You can also run the notebook in Jupyter or VS Code. Install Jupyter separately if needed, keep `data/` beside the notebook, and run all cells in order. The notebook uses the same code as `analysis.py`.

## Data and provenance

| File | Purpose |
| --- | --- |
| `data/raw/ember_monthly_global.csv` | Exact original public global download, about 28 MB |
| `data/kazakhstan_generation_snapshot.csv` | Unchanged national extraction: 102 consecutive months, January 2018–June 2026 |
| `data/source_checks/samruk_2018_january.docx` | Original January 2018 report used in the source audit |
| `data/source_checks/samruk_2018_q1.docx` | Original first-quarter 2018 report used in the source audit |
| `data/provenance.json` | Source URLs, download dates, sizes, SHA-256 hashes and extraction filters |

Source: [Ember Monthly Electricity Data](https://ember-energy.org/data/monthly-electricity-data/), downloaded **18 November 2026**. Filter `Area = Kazakhstan` and `Electricity source = Total generation`; target `Generation (TWh)`, renamed `Generation_TWh` in the national extraction. Ember publishes its data under **CC BY 4.0**. Credit Ember when reusing the data. The linked Samruk documents retain their original source attribution; this repository does not assign them a new license.

The main experiment uses **84 months from 2019–2025**:

| Stage | Period | Observations |
| --- | --- | --- |
| Initial training | 2019–2023 | 60 |
| Validation / order selection | 2024 | 12 |
| Held-out test | 2025 | 12 |

Every model predicts three months at a time at four quarterly origins. Parameters are refitted using expanding histories. The selected model order stays fixed during testing. No observation from inside a forecast block enters that block's training set.

### Why 2018 is excluded

Ember gives 9.780 TWh for each of January–March 2018. Samruk's January report gives **10.3573 TWh**. Its first-quarter report gives **29.3392 TWh**, close to Ember's summed **29.340 TWh**. This is consistent with temporal averaging but does not establish how every observation was constructed. No values were manually corrected. The main sample excludes 2018 and a sensitivity check adds it back without retuning. Other repeated observations remain a limitation.

The partial 2026 year is outside the main calendar-year experiment. The January–March 2026 forecasts are explicitly dated illustrations using information through December 2025, not live forecasts made in November 2026.

## Limitations and preparation

The data are a frozen revised snapshot, rather than the data vintages available at each historical origin. Only part of the source chain was independently audited. A single test year and four forecast origins limit generalization. The univariate model omits weather, outages, trade and policy, and generation is distinct from demand. The point-forecast improvement does not establish well-calibrated uncertainty.
